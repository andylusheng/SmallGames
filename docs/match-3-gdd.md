## 1. 游戏概述

### 1.1 一句话定义
交换相邻水果，连成 3 个或以上即可消除，在限定步数内完成关卡目标。经典三消玩法，水果主题，零内购即时开玩。

### 1.2 与对对碰的差异

| 维度 | 对对碰 | 消消乐（本作） |
|---|---|---|
| 核心动作 | 点两个相同水果直接消除 | 交换相邻水果形成三连 |
| 棋盘变化 | 消除后留空位，不补充 | 消除后下落+顶部补充，持续连锁 |
| 限制 | 时间限制 | 步数限制（部分关限时） |
| 策略深度 | 找配对即可 | 需要预判连锁、特殊水果合成 |
| 关卡目标 | 清空棋盘 | 分数/消除指定水果/收集物品 |
| 特殊元素 | 金色/冰冻/炸弹/倒计时 | 条纹/包装/彩虹水果 + 障碍 |

### 1.3 目标用户
- 休闲玩家：单局 1-3 分钟，碎片时间
- 三消老玩家：熟悉 Candy Crush / Royal Match 机制，追求连锁爽感
- 浏览器用户：免下载、无内购、加载快

## 2. 核心机制

### 2.1 棋盘
- **标准棋盘**：8×8（64 格），前期关卡用 6×6 / 7×7 教学
- **水果种类**：基础 6 种（🍎🍇🍊🍋🍉🍓），后期加 🥝🍒 到 8 种
- **格子状态**：普通 / 冰块（需消除两次）/ 锁链（需消除一次解锁）/ 空（不可放置）

### 2.2 交换规则
- 选中一个水果，再点相邻（上下左右）水果进行交换
- 交换后若形成 ≥3 同色连线 → 消除；否则交换回弹（无效交换不扣步数）
- 支持拖拽交换：按住水果拖向相邻格，松手即交换
- 交换动画 150ms，回弹动画 200ms

### 2.3 匹配与消除
- **直线匹配**：横向或纵向 ≥3 个同色水果连成一线
- **匹配优先级**：同时形成多个匹配时全部消除
- **消除动画**：水果缩放消失 + 白光闪光 + 彩色粒子爆裂（12 粒子/个）+ 分数飘字
- **消除时长**：单批消除 250ms，连锁批次间隔 200ms

### 2.4 下落与补充
- 消除后，上方水果受重力下落（每格 80ms，带缓动）
- 顶部生成新水果补充空位
- 下落后自动检测新匹配 → 连锁消除（cascade）
- 连锁无上限，直到棋盘稳定

### 2.5 连锁（Cascade）
- 一次交换触发的连续消除批次称为连锁
- 连锁倍率：第 1 批 ×1，第 2 批 ×1.5，第 3 批 ×2，第 4 批 ×2.5，第 5+ 批 ×3
- 连锁时屏幕显示 "Combo x2!" "Combo x3!" 飘字，伴随震屏
- 连锁音效递进（音调逐批升高）

### 2.6 步数系统
- 每关限定步数（如 20 步、25 步、30 步）
- 有效交换（形成匹配）扣 1 步
- 无效交换（回弹）不扣步
- 步数为 0 仍未完成目标 → 失败
- 剩余步数过关时：每步 ×50 分奖励

## 3. 特殊水果

### 3.1 条纹水果（Striped）
- **合成条件**：4 个同色水果直线消除（横向 4 连 → 横向条纹；纵向 4 连 → 纵向条纹）
- **外观**：水果上叠加横向/纵向白色条纹 + 微光
- **激活效果**：被消除时，清除整行（横向条纹）或整列（纵向条纹），带激光扫过特效
- **分数**：基础分 + 行/列每个水果 50 分

### 3.2 包装水果（Wrapped）
- **合成条件**：L 形或 T 形匹配（5 个水果组成 L/T）
- **外观**：水果外发光方框 + 脉冲呼吸
- **激活效果**：被消除时，3×3 范围爆炸（两次爆炸，先 3×3 再收缩再 3×3）
- **分数**：基础分 + 3×3 每个水果 60 分

### 3.3 彩虹水果（Rainbow / Color Bomb）
- **合成条件**：5 个同色水果直线消除
- **外观**：彩虹色旋转光环 + 水果图标居中
- **激活效果**：与任意水果交换 → 清除全场该颜色所有水果；与特殊水果交换 → 激活全场所有该类特殊水果
- **分数**：每个被清除水果 80 分

### 3.4 特殊水果联动
- 条纹 + 条纹：清除 3 行 + 3 列
- 条纹 + 包装：清除 3 行 + 3 列 + 中心 3×3 爆炸
- 包装 + 包装：5×5 范围大爆炸
- 彩虹 + 条纹：全场所有该色水果变条纹并激活
- 彩虹 + 彩虹：清屏（全场消除）

## 4. 障碍元素

### 4.1 冰块（Ice）
- **外观**：水果上覆盖半透明蓝色冰晶
- **规则**：覆盖的水果需消除 2 次才移除（第一次破冰，第二次消除）
- 条纹/包装/彩虹可直接破冰并消除

### 4.2 锁链（Chain）
- **外观**：水果上缠绕金属锁链
- **规则**：锁链水果不可移动，需消除 1 次解锁（解锁后变为普通水果）
- 特殊水果效果可解锁锁链

### 4.3 空格（Empty）
- **外观**：深色空洞
- **规则**：不可放置水果，水果下落到空格时跳过（从上方补充）
- 用于制造不规则棋盘形状

## 5. 关卡目标

### 5.1 目标类型

| 类型 | 描述 | 示例 |
|---|---|---|
| 分数目标 | 在步数内达到指定分数 | 达到 5000 分 |
| 消除指定水果 | 消除指定数量的某种水果 | 消除 20 个 🍇 |
| 收集物品 | 消除覆盖物品的水果来收集 | 收集 10 个果酱 |
| 限时挑战 | 限定时间内达到分数 | 60 秒内达到 8000 分 |
| 混合目标 | 同时完成 2-3 个目标 | 达到 3000 分 + 消除 15 个 🍊 |

### 5.2 星级评定
- 1 星：完成基础目标
- 2 星：分数达到目标的 1.5 倍
- 3 星：分数达到目标的 2.5 倍
- 星级影响关卡选择页展示和总星数

## 7. 计分系统

### 7.1 基础分数
| 动作 | 分数 |
|---|---|
| 3 连消除 | 60 分（每个 20） |
| 4 连消除 | 120 分（每个 30）+ 生成条纹 |
| 5 连消除 | 200 分（每个 40）+ 生成彩虹 |
| L/T 形消除 | 150 分 + 生成包装 |
| 条纹激活 | 行/列每格 50 分 |
| 包装激活 | 3×3 每格 60 分 |
| 彩虹激活 | 每个 80 分 |

### 7.2 连锁倍率
- 第 1 批：×1.0
- 第 2 批：×1.5
- 第 3 批：×2.0
- 第 4 批：×2.5
- 第 5+ 批：×3.0

### 7.3 剩余步数奖励
- 过关时每剩余 1 步 → 随机水果变条纹并激活 → 奖励分数
- 或简化为：每步 ×50 分直接加

## 8. UI/UX 设计

### 8.1 视觉风格
- **延续对对碰**：深色渐变背景（紫蓝）、水果立体光影、金色高亮
- **水果图标**：与对对碰统一（🍎🍇🍊🍋🍉🍓🥝🍒），多层渐变 + 高光 + 投影
- **棋盘**：深色台面，格子有微妙边框，选中水果双层呼吸光环
- **特殊水果**：条纹（白色线条叠加）、包装（发光方框）、彩虹（旋转光环）

### 8.2 屏幕流程
1. **开始页**：游戏标题 + 规则简介 + 开始游戏 + 选择关卡
2. **关卡选择**：6 章 × 10 关，星级展示，锁定/当前/已通关状态
3. **游戏中**：HUD（关卡/目标/步数/分数/暂停）+ 棋盘 + 目标进度条
4. **暂停**：继续 / 重开 / 退出
5. **胜利结算**：星级 + 分数 + 目标完成 + 下一关 / 重玩
6. **失败结算**：差多少 + 重玩 / 退出

### 8.3 HUD 布局
- 顶部：关卡号 | 目标图标+进度 | 剩余步数 | 分数 | 暂停按钮
- 棋盘居中
- 底部：道具栏（锤子/交换/洗牌，可选）

### 8.4 动效与反馈
- **交换**：150ms 平滑滑动，无效回弹 200ms
- **消除**：缩放消失 + 白光 + 12 粒子爆裂 + 分数飘字
- **下落**：80ms/格，带弹性缓动
- **连锁**：Combo 飘字 + 震屏（幅度递增）+ 音效递进
- **特殊激活**：条纹激光扫过、包装两次爆炸、彩虹全屏闪光
- **过关**：满屏粒子 + 星级逐个点亮 + 胜利音效

### 8.5 音效（WebAudio 合成）
- 选中：清脆 "叮"
- 交换：滑动 "唰"
- 消除：爆裂 "嘭"（3连低音，4连中音，5连高音）
- 连锁：音调逐批升高
- 特殊激活：激光/爆炸/彩虹专属音效
- 过关：胜利旋律
- 失败：低沉音

## 10. 技术方案

### 10.1 技术栈
- 单文件 `index.html`（Vanilla JS + CSS + WebAudio），与对对碰一致
- 棋盘用 CSS Grid 渲染，水果用 div + emoji（或 SVG）
- 动画用 CSS transition + transform，粒子用 Canvas 叠加层
- localStorage 保存进度（解锁关卡、星级、最高分）
- postMessage 事件：`runtime_ready` / `first_input` / `game_end{result,level,score,stars,moves}` / `level_start`
- `?selftest=1` 自动玩第 1 关（随机有效交换）

### 10.2 核心算法
1. **匹配检测**：遍历棋盘，检测横向/纵向 ≥3 连续同色
2. **交换验证**：模拟交换后检测是否有匹配，无则回弹
3. **下落算法**：每列从下往上扫描，空位由上方水果填充，顶部生成新水果
4. **连锁循环**：消除 → 下落 → 检测匹配 → 消除 → ... 直到稳定
5. **特殊水果生成**：检测匹配形状（4连/LT/5连），在匹配中心生成特殊水果
6. **死局检测**：棋盘稳定后检测是否存在有效交换，无则自动洗牌

### 10.3 关卡数据结构
```js
{
  level: 1,
  rows: 6, cols: 6,
  types: 5,
  moves: 30,
  goals: [{ type: 'score', target: 1000 }],
  obstacles: [], // [{row,col,type:'ice'|'chain'|'empty'}]
  powerups: { hammer: 2, shuffle: 1 }
}
```

### 10.4 响应式
- 移动端优先：棋盘占满宽度，格子自适应
- 桌面端：棋盘最大 480px，居中
- 支持触摸和鼠标

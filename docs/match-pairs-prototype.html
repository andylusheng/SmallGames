🎨 v0.4 细节优化说明

配对连线：选中第一颗后点同款，两颗之间出现金白渐变发光连线（流动虚线动画），两端有白色光点，连线停留 ~200ms 后触发消除。这是对对碰的核心识别反馈。
消除爆裂感：白光闪光（径向渐变扩散）+ 白色扩散环 + 8 向彩色粒子飞散（带旋转淡出）+ 金色飘分上升（+160 ×4），combo 越高粒子数量和速度递增。
水果砖质感：多层渐变（亮顶→主色→暗底）+ 顶部椭圆高光 + 底部投影边（0 5px 0 #b8945e）+ 内阴影 + 半透明白边，呈现真实凸起瓷砖感；按压时下移 3px。
选中态：金色外发光 + 缩放 1.06 + 上浮 + 双层呼吸光环（::after 动画），明确告知"已选中，等待配对"。
棋盘台面：深色微渐变 + 内阴影（顶部凹陷感）+ 顶部微妙高光层（::after），空格做深凹陷（内阴影），与凸起水果砖形成凹凸对比。
COMBO 反馈：侧栏大数字弹出动画（comboPop），红金渐变文字 + 发光；移动端顶部 COMBO 条同步弹跳。
HUD 质感：玻璃拟态卡片（backdrop-blur + 内高光 + 细边框），倒计时圆环带内阴影，星级点亮时带金色发光。
双端一致：Web 与移动端共用同一套视觉语言、动画时序、特效参数；仅布局随宽度自适应（Web 右侧栏 / 移动底部栏）。
